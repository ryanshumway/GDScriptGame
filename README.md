# GDScriptGame

An original FTL-style, pausable real-time roguelite built in Godot 4.7 with
GDScript — and a learning project. See `LEARNING.md` for the glossary and
step-by-step notes.

## Running

1. Install Godot 4.7.2 (standard build, not .NET).
2. In the Project Manager, choose **Import** and select this folder's
   `project.godot`.
3. Press **F5** (or the ▶ button) to run.
